# AWS CloudOps Engineer Vocabulary Part 2

<details>
<summary>26. Elastic Throughput</summary>

Definition: One of the Throughput Modes in Amazon EFS that is recommended if you have spiky or unpredictable workloads and performance requirements that are difficult to forecast.

</details>

<br>

<details>
<summary>27. Bursting Throughput</summary>

Definition: A type of Amazon EFS Throughput Mode that is recommended if you want a throughput that scales with the amount of storage in your file system.

</details>

<br>

<details>
<summary>28. Amazon RDS</summary>

Definition: A collection of managed services that makes it simple to set up, operate, and scale relational databases in the cloud.

</details>

<br>

<details>
<summary>29. AWS CloudFormation</summary>

Definition: A service that lets you model, provision, and manage AWS and third-party resources by treating infrastructure as code.

</details>

<br>

<details>
<summary>30. AWS CLI</summary>

Definition: A unified tool to manage and control multiple AWS services from the command line and automate them through scripts.

</details>

<br>

<details>
<summary>31. AWS Compute Optimizer</summary>

Definition: Helps avoid overprovisioning and underprovisioning of various AWS resources such as Amazon EC2 instances, EBS volumes, ECS services on Fargate, and Lambda functions based on utilization data.

</details>

<br>

<details>
<summary>32. AWS Config</summary>

Definition: A service that continually assesses, audits, and evaluates the configurations and relationships of your resources on AWS, on-premises, and on other clouds.

</details>

<br>

<details>
<summary>33. AWS Health Dashboard</summary>

Definition: A single place to learn about the overall status of AWS services, view personalized communications about your AWS account, and receive alerts automatically triggered by changes in the health of services you are using.

</details>

<br>

<details>
<summary>34. AWS Systems Manager Parameter Store</summary>

Definition: A capability of AWS Systems Manager that provides secure, hierarchical storage for configuration data management and secrets management.

</details>

<br>

<details>
<summary>35. AWS Secrets Manager</summary>

Definition: A service that helps you manage, retrieve, and rotate database credentials, API keys, and other secrets throughout their lifecycles.

</details>

<br>

<details>
<summary>36. S3 Access Point</summary>

Definition: A feature of S3 that allows customers to create individualized access points with names and permissions customized for each of their applications.

</details>

<br>

<details>
<summary>37. Traffic Mirroring</summary>

Definition: An Amazon VPC feature that you can use to copy network traffic from an elastic network interface and send the traffic to out-of-band security and monitoring appliances for content inspection, threat monitoring, and troubleshooting. (Think: Wiretap for your network — you see the actual packets, not just metadata like Flow Logs.)

</details>

<br>

<details>
<summary>38. Amazon OpenSearch Service</summary>

Definition: A managed service that makes it easy for you to perform interactive log analytics, real-time application monitoring, and website search using an open-source, distributed search and analytics suite derived from Elasticsearch.

</details>

<br>

<details>
<summary>39. Amazon Aurora</summary>

Definition: A modern relational database service offering performance and high availability at scale, fully open-source MySQL- and PostgreSQL-compatible editions with a range of developer tools for building serverless and machine learning (ML)-driven applications.

</details>

<br>

<details>
<summary>40. AWS License Manager</summary>

Definition: A service that makes it easier for you to manage your software licenses from software vendors centrally across AWS and your on-premises environments.

</details>

<br>

<details>
<summary>41. AWS OpsWorks</summary>

Definition: A configuration management service that provides managed instances of Chef and Puppet. (Think: AWS runs Chef/Puppet for you so you can automate server configuration without managing the Chef/Puppet infrastructure yourself.)

</details>

<br>

<details>
<summary>42. AWS Organizations</summary>

Definition: An account management service that enables you to consolidate multiple AWS accounts into an organization that you create and centrally manage.

</details>

<br>

<details>
<summary>43. AWS Global Accelerator</summary>

Definition: A networking service that provides static IP addresses that act as a fixed entry point to your applications and eliminate the complexity of managing specific IP addresses for different AWS Regions and Availability Zones.

</details>

<br>

<details>
<summary>44. Amazon Detective</summary>

Definition: Automatically collects log data from your AWS resources and uses machine learning, statistical analysis, and graph theory to build a linked set of data that enables you to easily conduct faster and more efficient security investigations.

</details>

<br>

<details>
<summary>45. AWS Directory Service</summary>

Definition: Allows you to easily set up and run directories in the AWS Cloud, or connect your AWS resources with an existing on-premises Microsoft Active Directory.

</details>

<br>

<details>
<summary>46. AWS Firewall Manager</summary>

Definition: A security management service that allows you to centrally configure and manage firewall rules across your accounts and applications in AWS Organizations. As new applications are created, Firewall Manager makes it easier to bring new applications and resources into compliance by enforcing a common set of security rules.

</details>

<br>

<details>
<summary>47. AWS Shield Advanced</summary>

Definition: A managed service at an additional fee that provides enhanced protection against more advanced DDoS attacks and near real-time notifications on suspected DDoS incidents.

</details>

<br>

<details>
<summary>48. AWS Transit Gateway</summary>

Definition: Connects Amazon VPCs, AWS accounts, and on-premises networks to a single gateway by acting as a centralized hub, connecting multiple VPCs and on-premises networks in a hub-and-spoke architecture.

</details>

<br>

<details>
<summary>49. Amazon Route 53 Resolver</summary>

Definition: The built-in DNS service in every VPC that responds recursively to DNS queries from AWS resources for public records, Amazon VPC-specific DNS names, and Amazon Route 53 private hosted zones. (Think: The front desk receptionist that looks up addresses for you.)

</details>

<br>

<details>
<summary>50. Amazon RDS Proxy</summary>

Definition: A fully-managed database proxy feature of Amazon RDS that pools and shares database connections, reducing failover times, preserving application connections during failovers, and enforcing AWS IAM authentication. (Think: A middleman that prevents your database from being overwhelmed by too many connections, especially useful for Lambda.)

</details>
