# AWS CloudOps Engineer Vocabulary Part 3

<details>
<summary>51. S3 Transfer Acceleration</summary>

Definition: Creates fast, easy, and secure transfers of files over long distances between your client and your Amazon S3 bucket by leveraging Amazon CloudFront's globally distributed AWS Edge locations. As data arrives at an AWS Edge Location, data is routed to your Amazon S3 bucket over an optimized network path.

</details>

<br>

<details>
<summary>52. AWS Auto Scaling</summary>

Definition: Using this service, it's easy to set up application scaling for multiple resources across multiple services in minutes.

</details>

<br>

<details>
<summary>53. Amazon EC2 Auto Scaling</summary>

Definition: This service helps you ensure that you have the correct number of Amazon EC2 instances available to handle the load for your application.

</details>

<br>

<details>
<summary>54. Amazon EC2 Image Builder</summary>

Definition: A fully-managed AWS service that makes it easier to automate the creation, management, and deployment of customized, secure, and up-to-date "golden" server images that are pre-installed and pre-configured with software and settings to meet specific IT standards.

</details>

<br>

<details>
<summary>55. Amazon DynamoDB</summary>

Definition: A fully managed NoSQL database service that provides fast and predictable performance with seamless scalability.

</details>

<br>

<details>
<summary>56. AWS Tools and SDKs</summary>

Definition: A collection of software libraries, command-line tools, and plugins for IDEs that are designed to help developers build, deploy, and manage applications on AWS.

</details>

<br>

<details>
<summary>57. AWS Management Console</summary>

Definition: It provides a unified interface for accessing and interacting with a wide range of AWS services.

</details>

<br>

<details>
<summary>58. AWS Service Catalog</summary>

Definition: It enables IT administrators to create, manage, and distribute portfolios of approved products to end users, who can then access the products they need in a personalized portal.

</details>

<br>

<details>
<summary>59. AWS Systems Manager</summary>

Definition: This service allows you to organize, monitor, and automate management tasks on your AWS resources.

</details>

<br>

<details>
<summary>60. AWS Trusted Advisor</summary>

Definition: It inspects your AWS environment, and then makes recommendations when opportunities exist to save money, improve system availability and performance, or help close security gaps.

</details>

<br>

<details>
<summary>61. AWS DataSync</summary>

Definition: An online data movement and discovery service that simplifies data migration and helps you quickly, easily, and securely transfer your file or object data to, from, and between AWS storage services.

</details>

<br>

<details>
<summary>62. AWS Transfer Family</summary>

Definition: This service simplifies the migration of SFTP, FTPS, FTP, and AS2 workflows to AWS.

</details>

<br>

<details>
<summary>63. Amazon CloudFront</summary>

Definition: You can use this service to speed up the distribution of your static and dynamic web content, such as .html, .css, .php, image, and media files.

</details>

<br>

<details>
<summary>64. Elastic Load Balancing (ELB)</summary>

Definition: It automatically distributes your incoming traffic across multiple targets, such as EC2 instances, containers, and IP addresses, in one or more Availability Zones.

</details>

<br>

<details>
<summary>65. Amazon Route 53</summary>

Definition: You can use this service to perform three main functions in any combination: domain registration, DNS routing, and health checking.

</details>

<br>

<details>
<summary>66. Amazon VPC</summary>

Definition: It enables you to provision a logically isolated section of the AWS Cloud where you can launch AWS resources in a virtual network that you've defined.

</details>

<br>

<details>
<summary>67. AWS VPN</summary>

Definition: Creates a secure and private tunnel between your device and AWS Cloud.

</details>

<br>

<details>
<summary>68. AWS Certificate Manager (ACM)</summary>

Definition: It handles the complexity of creating, storing, and renewing public and private SSL/TLS X.509 certificates and keys that protect your AWS websites and applications.

</details>

<br>

<details>
<summary>69. Amazon GuardDuty</summary>

Definition: It can help to identify unexpected and potentially unauthorized or malicious activity in your AWS environment. (Think: "Is someone doing something shady?")

</details>

<br>

<details>
<summary>70. AWS Identity and Access Management (IAM)</summary>

Definition: Using this service, you can centrally manage users, security credentials such as access keys, and permissions that control which AWS resources users and applications can access.

</details>

<br>

<details>
<summary>71. AWS IAM Access Analyzer</summary>

Definition: By identifying policies that grant access to external principals, this tool helps identify potential resource-access risks. (Think: "You're sharing resources with outsiders — did you mean to?")

</details>

<br>

<details>
<summary>72. Amazon Inspector</summary>

Definition: A security vulnerability assessment service that scans your EC2 instances and container images for known software vulnerabilities (CVEs). (Think: "Your software has known security holes.")

</details>

<br>

<details>
<summary>73. AWS Key Management Service (AWS KMS)</summary>

Definition: A managed service that makes it easy for you to create and control the cryptographic keys that are used to protect your data.

</details>

<br>

<details>
<summary>74. AWS Security Hub</summary>

Definition: Collects security data from across AWS accounts and services, and helps you analyze your security trends to identify and prioritize the security issues across your AWS environment.

</details>

<br>

<details>
<summary>75. AWS Shield</summary>

Definition: It provides protection against a wide range of known DDoS attack vectors and zero-day attack vectors.

</details>
