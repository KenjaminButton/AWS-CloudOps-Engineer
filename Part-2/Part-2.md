# AWS CloudOps Engineer Vocabulary Part 2

<details>
<summary>26. AWS Lambda </summary>

Definition: A serverless, event-driven compute service that lets you run code for virtually any type of application or backend service without provisioning or managing servers.

</details>

<details>
<summary>27. Amazon Aurora Global Database</summary>

Definition: A highly-scalable and highly-available AWS database service that can provide your application with an effective recovery point objective (RPO) of 1 second and a recovery time objective (RTO) of less than 1 minute

</details>

<details>
<summary>28. Amazon ElastiCache </summary>

Definition: A fully managed, Redis and Memcached compatible service delivering real-time, cost-optimized performance for modern applications. 

</details>

<details>
<summary>29. Elastic Throughput </summary>

Definition: One of the Throughput Modes in Amazon EFS that is recommended if you have spiky or unpredictable workloads and performance requirements that are difficult to forecast

</details>

<details>
<summary>30. Bursting Throughput </summary>

Definition: A type of Amazon EFS Throughput Mode that is recommmended if you want a throughput that scales with the amount of storage in your file system. 

</details>

<details>
<summary>31. Amazon RDS </summary>

Definition: A collection of managed services that makes it simple to set up, operate, and scale relational databases in the cloud.

</details>

<details>
<summary>32. AWS CloudFormation </summary>

Definition: A service that lets you model, provision, and manage AWS and third-party resources by treating infrastructure as code.

</details>

<details>
<summary>33. AWS CLI </summary>

Definition: A unified tool to manage and control multiple AWS services from the command line and automate them through scripts.

</details>

<details>
<summary>34. AWS Compute Optimizer </summary>

Definition: Helps avoid overprovisioning and underprovisioning of various AWS resources such as Amazon EC2 instances, EBS volumes, ECS services on Fargate, and Lambda functions based on utilization data.

</details>

<details>
<summary>35. AWS Config </summary>

Definition: A service that continually assesses, audits, and evaluates the configurations and relationships of your resources on AWS, on-premises, and on other clouds. 

</details>

<details>
<summary>36. AWS Health Dashboard </summary>

Definition: A single place to learn about the overall status of AWS services, and view personalized communications about your particular AWS account or organization.

</details>

<details>
<summary>37.AWS Systems Manager Parameter Store</summary>

Definition: A capability of AWS Systems Manager that provides secure, hierarchical storage for configuration data management and secrets management. 

</details>

<details>
<summary>38. AWS Secrets Manager</summary>

Definition: A service that helps you manage, retrieve, and rotate database credentials, API keys, and other secrets throughout their lifecycles. 

</details>

<details>
<summary>39. S3 Access Point</summary>

Definition: A feature of S3 that allows customers to create individualized access points with names and permissions customized for each of their application. 

</details>

<details>
<summary>40. Traffic Mirroring</summary>

Definition: (WireTap Analogy for VPC Flow Logs) An Amazon VPC feature that you can use to copy network traffic from an elastic network interface and send the traffic to out-of-band security and monitoring appliances for content inspection, threat monitoring and troubleshooting.

</details>

<details>
<summary>41. Amazon OpenSearch Service </summary>

Definition: A managed service that makes it easy for you to perform interactive log analytics, real-time application monitoring, and website search using an open-source, distributed search and analytics suite derived from Elasticsearch.

</details>

<details>
<summary>42. Amazon Aurora</summary>

Definition: A modern relational database service offering performance and high availability at scale, fully open-source MySQL - and PostgreSQL - compatible editions with a range of developer tools for building serverless and machine learning (ML) - driven applications. 

</details>

<details>
<summary>43. AWS License Manager</summary>

Definition: A service that makes it easier for you to manage your software license from software vendors centrally across AWS and your on-premises environments. 

</details>

<details>
<summary>44. AWS OpsWorks</summary>

Definition: A configuration management service that provides managed instances of Chef and Puppet

</details>

<details>
<summary>45. AWS Organizations </summary>

Definition: An account management service that enables you to consolidate multiple AWS accounts into an organization that you create and centrally manage. 

</details>

<details>
<summary>46. AWS Personal Health Dashboard</summary>

Definition: Provides a personalized view into the performance and availability of the AWS services you are using, as well as alerts that are automatically triggered by changes in the health of those services. 

</details>

<details>
<summary>47. AWS DataSync </summary>

Definition: A secure, online service that automates and accelerates moving data between on-presmises and AWS storage services. 

</details>

<details>
<summary>48. AWS Global Accelerator </summary>

Definition: A networking service that provides static IP addresses that act as a fixed entry point to your applications and eliminate the complexity of managing specific IP addresses for different AWS Regions and Availability Zones.

</details>

<details>
<summary>49. Amazon Detective </summary>

Definition: Automatically collects log data from your AWS resources and uses machine learning, statistical analysis, and graph theory to build a linked set of data that enables you to easily conduct faster and more efficient security investigations. 

</details>

<details>
<summary>50. AWS Directory Service </summary>

Definition: Allows you to easily setup and run directories in the AWS Cloud, or connect your AWS resources with an existing on-premisis Microsoft Active Directory.

</details>
