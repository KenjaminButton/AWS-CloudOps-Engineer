# AWS CloudOps Engineer Vocabulary Part 1

<details>
<summary>1. Amazon CloudWatch</summary>

Definition: A web service that enables you to monitor and manage various metrics, and configure alarm actions.

</details>

<br>

<details>
<summary>2. AWS CloudTrail</summary>

Definition: A web service that logs AWS API calls and tracks the deletion and rotation of CMKs.

</details>

<br>

<details>
<summary>3. SurgeQueueLength</summary>

Definition: A count of the total number of requests that are pending submission to a registered instance.

</details>

<br>

<details>
<summary>4. Multi-AZ Amazon FSx</summary>

Definition: Highly available File Server that supports SMB and manages file permissions using Windows Access Control List (ACL).

</details>

<br>

<details>
<summary>5. Nested Stacks</summary>

Definition: A CloudFormation template that can be used for multiple environments. If the template has been updated, all the stacks that are referencing it will automatically use the updated configuration.

</details>

<br>

<details>
<summary>6. AWS Service Catalog TagOption Library</summary>

Definition: Enforces the tagging of all instances that will be launched in the VPC.

</details>

<br>

<details>
<summary>7. AWS Systems Manager Patch Manager</summary>

Definition: Automates the process of patching managed instances with security-related updates.

</details>

<br>

<details>
<summary>8. Amazon Athena</summary>

Definition: Analyzes the data hosted in Amazon S3 using standard SQL.

</details>

<br>

<details>
<summary>9. Amazon Cognito User Pools</summary>

Definition: Enables authentication to AWS services using Active Directory Federation Services.

</details>

<br>

<details>
<summary>10. Route 53 Geoproximity Routing Policy</summary>

Definition: Ensures that users are consistently directed to the AWS region nearest to them.

</details>

<br>

<details>
<summary>11. VPC Endpoint</summary>

Definition: Enables private connectivity to services hosted in AWS, from within your VPC without using an internet gateway, VPN, NAT devices, or firewall proxies.

</details>

<br>

<details>
<summary>12. AWS Shield Standard</summary>

Definition: Provides protection against SYN Floods, DNS query floods, UDP reflection attacks, and other DDoS attacks to your AWS workloads at absolutely no cost.

</details>

<br>

<details>
<summary>13. AWS Snowball</summary>

Definition: A service that accelerates transferring large amounts of data into and out of AWS using physical storage appliances, bypassing the internet.

</details>

<br>

<details>
<summary>14. AWS Control Tower</summary>

Definition: Allows you to set up and govern a secure, multi-account AWS environment.

</details>

<br>

<details>
<summary>15. Amazon EventBridge</summary>

Definition: A service that allows you to build event-driven applications at scale across AWS, existing systems, or SaaS applications.

</details>

<br>

<details>
<summary>16. Amazon SNS</summary>

Definition: A fully managed Pub/Sub service for Application-to-Application (A2A) and Application-to-Person (A2P) messaging.

</details>

<br>

<details>
<summary>17. Amazon SQS</summary>

Definition: A fully managed message queuing service for microservices, distributed systems, and serverless applications.

</details>

<br>

<details>
<summary>18. AWS Cost and Usage Report</summary>

Definition: Provides the most detailed information about your AWS bill and can generate reports with hourly, daily, or monthly granularity. Reports are stored in your selected S3 bucket and can be analyzed using Amazon Athena, Amazon Redshift, or Amazon QuickSight.

</details>

<br>

<details>
<summary>19. AWS Cost Explorer</summary>

Definition: An easy-to-use interface that lets you visualize your AWS costs and provides a set of ready-to-use default reports to help you get started.

</details>

<br>

<details>
<summary>20. Savings Plans</summary>

Definition: A flexible pricing model that can help you reduce your bill by up to 72% compared to On-Demand prices, in exchange for a one- or three-year hourly spend commitment.

</details>

<br>

<details>
<summary>21. MAX I/O</summary>

Definition: An Amazon EFS performance mode that is designed for highly parallelized workloads that can tolerate high latencies.

</details>

<br>

<details>
<summary>22. General Purpose</summary>

Definition: A type of Performance Mode in Amazon EFS that provides the lowest per-operation latency.

</details>

<br>

<details>
<summary>23. AWS Lambda</summary>

Definition: A serverless, event-driven compute service that lets you run code for virtually any type of application or backend service without provisioning or managing servers.

</details>

<br>

<details>
<summary>24. Amazon Aurora Global Database</summary>

Definition: A highly-scalable and highly-available AWS database service that can provide your application with an effective recovery point objective (RPO) of 1 second and a recovery time objective (RTO) of less than 1 minute.

</details>

<br>

<details>
<summary>25. Amazon ElastiCache</summary>

Definition: A fully managed, Redis and Memcached compatible service delivering real-time, cost-optimized performance for modern applications.

</details>
