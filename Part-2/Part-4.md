# AWS CloudOps Engineer Vocabulary Part 4

<details>
<summary>76. AWS Identity and Access Management (IAM) </summary>

Definition: Using this service, you can centrally manage users, security credentials such as access keys, and permissions that control which AWS resources users and applications can access.

</details>

<details>
<summary>77. AWS Identity and Access Management Access Analyzer</summary>

Definition: By identifying policies that grant access to external principals (who can access something), this tool helps identify potential resource-access risks. 

</details>

<details>
<summary>78. Amazon Inspector</summary>

Definition: A security vulnerability assessment service that helps improve the security and compliance of your AWS resources.

</details>

<details>
<summary>79. AWS Key Management Service (AWS KMS) </summary>

Definition: A managed service that makes it easy for you to create and control the cryptographic keys that are used to protect your data. 

</details>

<details>
<summary>80.AWS Security Hub </summary>

Definition: Collects security data from across AWS accounts and services, and helps you analyze your security trends to identify and prioritize the security issues across your AWS environment. 

</details>

<details>
<summary>81. AWS Shield </summary>

Definition: It provides protection against a wide range of known DDoS attack vectors and zero-day attack vectors. 

</details>

<details>
<summary>82. AWS WAF</summary>

Definition: A web application firewall that lets you monitor and manage web requests that are forwarded to protected AWS resources.

</details>

<details>
<summary>83. AWS Backup </summary>

Definition: A fully managed backup service that makes it easy to centralize and automate the backup of data across AWS services in the cloud as well as on premises. 

</details>

<details>
<summary>84. Amazon Elastic Block Store (Amazon EBS) </summary>

Definition: Provides block level storage volumes for use with EC2 instances.

</details>

<details>
<summary>85. Amazon Elastic File System (Amazon EFS) </summary>

Definition: It is built to scale on demand to petabytes without disrupting applications, growing and shrinking automatically as you add and remove files.

</details>

<details>
<summary>86. Amazon FSx</summary>

Definition: Makes it easy and cost effective to launch, run, and scale feature-rich, high performance file systems in the cloud. 

</details>

<details>
<summary>87. Amazon S3 </summary>

Definition: It is an object storage service that offers industry-leading scalability, data availability, security, and performance.

</details>

<details>
<summary>88. Amazon S3 Glacier </summary>

Definition: This is a storage service that is designed to store data that is not frequently accessed or used, also known as "cold data."

</details>

<details>
<summary>89. AWS Storage Gateway </summary>

Definition: A service that connects an on-premises software appliance with cloud-based storage to provide seamless and secure integration between your on-premises IT environment and the AWS storage infrastructure in the AWS Cloud. 

</details>

<details>
<summary>90. EBS volume</summary>

Definition: A durable, block-level storage device that you can attach to your instances.

</details>

<details>
<summary>91. Read Replica</summary>

Definition: A read-only copy of a DB instance.

</details>

<details>
<summary>92. AWS Step Functions </summary>

Definition: A visual workflow manager that coordinates multiple AWS services in a defined sequence, handling retries, parallel execution, and error handling automatically.

</details>

<details>
<summary>93. Scale Up</summary>

Definition: Get a BIGGER machine. Scale Out vs Scale In. Scale Up vs Scale Down

</details>

<details>
<summary>94. Scale Down </summary>

Definition: Reduce read and write capacity by adjusting the node type down to use a smaller node.

</details>

<details>
<summary>95. Spot Instances</summary>

Definition: It enables you to request unused EC2 instances at steep discounts, and you can lower your Amazon EC2 costs significantly. 

</details>

<details>
<summary>96. On-Demand Instances</summary>

Definition: You pay for compute capacity by the second with no long-term commitments

</details>

<details>
<summary>97. Reserved Instances</summary>

Definition: It provides you with significant savings on your Amazon EC2 costs compared to On-Demand Instance pricing.

</details>

<details>
<summary>98. AWS Direct Connect</summary>

Definition: Links your internal network to an AWS Direct Connect location over a standard Ethernet fiber-optic cable. 

</details>

<details>
<summary>99. Convertible Reserved Instances</summary>

Definition: It can be exchanged during the term for another Convertible Reserved Instance with new attributes, including instance family, instance type, platform, scope, or tenancy.

</details>

<details>
<summary>100. NAT Gateway</summary>

Definition: You can use this so that instances in a private subnet can connect to services outside your VPC, but external services cannot initiate a connection with those instances. 

</details>
