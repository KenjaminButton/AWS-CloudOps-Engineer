# AWS CloudOps Engineer Vocabulary Part 3

<details>
<summary>51. AWS Firewall Manager </summary>

Definition: A security management service that allows you to centrally configure and manage firewall rules across your accounts and applications in AWS Organizations. As new applications are created, Firewall Manager makes it easier to bring new applications and resources into compliance by ennforcing a common set of security rules. 

</details>

<details>
<summary>52. AWS Shield Advanced </summary>

Definition: A managed service at an additional fee that provides enhanced protection against more advanced DDoS attacks and near real-time notifications on suspected DDoS incidents. 

</details>

<details>
<summary>53. AWS Transit Gateway</summary>

Definition: Connect Amazon VPCs, AWS accounts, and on-premises networks to a single gateway by acting as a centralized hub, connecting multiple VPCs and on-premises networks in a hub-and-spoke architecture.

</details>

<details>
<summary>54. Amazon Route 53 Resolver </summary>

Definition: Responds recursively to DNS queries from AWS resources for public records, Amazon VPC-specific DNS names, and Amazon Route 53 private hosted zones, and is available by default in all VPCs. 

</details>

<details>
<summary>55. Amazon RDS Proxy</summary>

Definition: A fully-managed database proxy feature of Amazon RDS that enhances scalability, availability, and security for your applications by pooling and sharing database connections, reducing failover times, preserving application connections during failovers, and enforcing AWS IAM authentication and securely storing credentials in AWS Secrets Manager. 

</details>

<details>
<summary>56. S3 Transfer Acceleration</summary>

Definition: Create fast, easy, and secure transfers of files over long distances between your client and your Amazon S3 bucket by leveraging Amazon Cloudfront's globally distributed AWS Edge locations. As data arrives at an AWS Edge Location, data is routed to your Amazon S3 bucket over an optimized network path. 

</details>

<details>
<summary>57. AWS Auto Scaling </summary>

Definition: Using this service, it's easy to setup application scaling for multiple resources across multiple services in minutes. 

</details>

<details>
<summary>58. Amazon EC2 Auto Scaling </summary>

Definition: This service helps you to ensure that you have the correct number of Amazon EC2 instances available to handle the load for your application. 

</details>

<details>
<summary>59. Amazon EC2 Image Builder </summary>

Definition: A fully-managed AWS service that makes it easier to automate the creation,management, and deployment of customized, secure, and up-to-date "golden" server images that are pre-installed and pre-configured with software and settings to meet specific IT standards

</details>

<details>
<summary>60. Amazon DynamoDB</summary>

Definition: A fully managed NoSQL database service taht provides fast and predictable performance with seamless scalability

</details>

<details>
<summary>61. AWS Tools and SDKs</summary>

Definition: A collection of software libraries, command-line tools, and plugins for IDEs that are designed to help developers build, deploy, and manage applications on AWS.

</details>

<details>
<summary>62. AWS Management Console</summary>

Definition: It provides a unified interface for accessing and interacting with a wide range of AWS services.

</details>

<details>
<summary>63. AWS Service Catalog </summary>

Definition: It enables IT administrators to create, manage, and distribute portfolios of approved products to end users, who can then access the products they need in a personalized portal. 

</details>

<details>
<summary>64. AWS Systems Manager</summary>

Definition: This service allows you to organize, monitor, and automate management tasks on your AWS resource. 

</details>

<details>
<summary>65. AWS Trusted Advisor </summary>

Definition: It inspects your AWS environment, and then makes recommendations when opportunities exist to save money, improve system availability and performance, or help close security gaps. 

</details>

<details>
<summary>66. AWS DataSync </summary>

Definition: An online data movement and discovery service that simplifies data migration and helps you quickly, easily, and securely transfer your file or object data to, from, and between AWS storage services. 

</details>

<details>
<summary>67. AWS Transfer Family </summary>

Definition: This service simplifies the migration of (SFTP), (FTPS), (FTP), and (AS2) workflows to AWS.

</details>

<details>
<summary>68. Amazon Cloudfront </summary>

Definition: You can use this service to speed up the distribution of your static and dynamic web content, such as .html, .css, .php, image, and media files. 

</details>

<details>
<summary>69. Elastic Load Balancing (ELB) </summary>

Definition: It automatically distributes your incoming traffic across multiple targets, such as EC2 instances, containers, and IP addresses, in one or more Availability Zones. 

</details>

<details>
<summary>70. Amazon Route 53 </summary>

Definition: You can use this service to perform three main functions in any combination: domain registration, DNS routing, and health checking. 

</details>

<details>
<summary>71. Amazon VPC</summary>

Definition: It enables you to provision a logically isolated section of the AWS Cloud where you can launch AWS resources in a virtual network that you've defined. 

</details>

<details>
<summary>72. AWS VPN </summary>

Definition: Creates a secure and private tunnel between your device and AWS Cloud.

</details>

<details>
<summary>73. AWS Certificate Manager (ACM)  </summary>

Definition: It handles the complexity of creating, storing, and renewing public and private SSL/TLS X.509 certificates and keys that protect your AWS websites and applications. 

</details>

<details>
<summary>74. AWS Firewall Manager </summary>

Definition: This service simplifies your AWS WAF administration and maintanance tasks across multiple accounts and resources. 

</details>

<details>
<summary>75. Amazon GuardDuty </summary>

Definition: It can help to identify unexpected and potentially unauthorized or malicious activity in your AWS environment. 

</details>
